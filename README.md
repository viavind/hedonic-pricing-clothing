# Hedonic Pricing Analysis of Clothing Products

An analysis of clothing product prices using Hedonic Pricing and Linear Regression to examine how product attributes relate to price.

## Objective

The project aims to:
- Analyze the relationship between product attributes and price
- Identify attributes that contribute to price differences
- Explore pricing patterns based on product characteristics

## Dataset

The dataset contains clothing product information with the following attributes:
- Brand
- Category
- Color
- Size
- Material
- Price

## Methodology

1. Exploratory Data Analysis
2. Data Cleaning
3. Feature Selection
4. One-Hot Encoding
5. Train-Test Split
6. Hedonic Regression using Linear Regression
7. Model Evaluation
8. Regression Coefficient Analysis

## Evaluation

The model was evaluated using:
- Mean Absolute Error (MAE)
- R² Score

The resulting R² was relatively low, indicating that the selected product attributes did not sufficiently explain the variation in product prices.
